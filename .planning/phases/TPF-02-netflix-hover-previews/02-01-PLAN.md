Output: `HoverPreviewContext.tsx` and `HoverPreviewPortal.tsx`.

    Create `apps/viewer/src/context/HoverPreviewContext.tsx`:
    1. Define interface `HoverPreviewState`:
       - `activeFilm: Film | null`
       - `sourceRect: DOMRect | null`
       - `isOpen: boolean`
       - `triggerEnter: (film: Film, rect: DOMRect) => void`
       - `triggerLeave: () => void`
       - `portalEnter: () => void`
       - `portalLeave: () => void`
       - `closeImmediately: () => void`
    2. Manage state with timers:
       - `enterTimeoutRef`: 350ms timer. If triggered, sets `activeFilm`, `sourceRect`, and `isOpen: true`.
       - `leaveTimeoutRef`: 200ms grace timer. If mouse leaves triggering card or preview portal, waits 200ms before setting `isOpen: false` and clearing active film.
       - If `portalEnter` is called within the 200ms grace window, clear `leaveTimeoutRef` so the preview remains active while the user interacts with buttons.
    3. Export `HoverPreviewProvider` and custom hook `useHoverPreview()`.
  </action>

    Create `apps/viewer/src/components/catalog/HoverPreviewPortal.tsx`:
    1. Consume `useHoverPreview()`. Return `null` if not open or no `activeFilm` or no `sourceRect`.
    2. Use `createPortal(..., document.body)`.
    3. Compute clamped position:
       - Target card width: `const targetWidth = Math.min(360, Math.max(300, sourceRect.width * 1.35))`.
       - Target card height: proportional 16:9 media header + info body.
       - Center alignment: `const centerX = sourceRect.left + sourceRect.width / 2`.
       - Clamped X: `const clampedX = Math.max(16, Math.min(window.innerWidth - targetWidth - 16, centerX - targetWidth / 2))`.
       - Clamped Y: `const clampedY = Math.max(80, sourceRect.top - 16)`.
    4. Render `motion.div` with `position: fixed`, `left: clampedX`, `top: clampedY`, `width: targetWidth`, `zIndex: 50`.
    5. Animate with Framer Motion spring:
       - Initial: `{ opacity: 0, scale: 0.92, y: 10 }`
       - Animate: `{ opacity: 1, scale: 1, y: 0 }`
       - Exit: `{ opacity: 0, scale: 0.94, transition: { duration: 0.15 } }`
    6. Mount `<HoverPreviewPortal />` and wrap `<HoverPreviewProvider>` in `apps/viewer/src/App.tsx`.
  </action>

    <automated>npm run build:viewer</automated>
