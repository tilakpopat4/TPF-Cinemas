## Tasks

### T-07-01-01 · DB Migration — add `update_pending` to film_status enum
**Type:** tracer
**Reversibility:** one-way (enum extension is additive; no rollback without migration)

Add `update_pending` to the `film_status` Postgres enum. Also add the `film_updates` table that
will hold proposed changes from creators (used in Plan 07-02).

Create file: `supabase/migrations/20261005000001_film_updates.sql`

Content:
- `ALTER TYPE public.film_status ADD VALUE IF NOT EXISTS 'update_pending';`
- `CREATE TABLE public.film_updates` with columns: id, film_id, filmmaker_id, proposed_changes (jsonb), status ('pending'|'approved'|'rejected'), reviewer_id, reviewer_notes, reviewed_at, created_at, updated_at
- Indexes on film_id and status
- RLS policies: creator reads own, staff reads all, creator inserts only for published films they own
- GRANTS: SELECT and limited INSERT to authenticated
- RPC `propose_film_update(p_film_id uuid, p_changes jsonb) RETURNS uuid`:
  - Validates caller owns a published film
  - Rejects if a pending update already exists for the film
  - Inserts to film_updates, sets films.status = 'update_pending', logs action
- RPC `apply_film_update(p_update_id uuid, p_notes text) RETURNS void`:
  - is_staff() check
  - Whitelisted field merge: only title, synopsis, director_note, runtime_minutes, language, release_year, age_rating, poster_url, video_provider, video_ref, is_debut can be updated (no status/is_featured escalation)
  - Restores films.status = 'published', marks update 'approved', logs action
- RPC `reject_film_update(p_update_id uuid, p_notes text) RETURNS void`:
  - is_staff() check, min 10-char notes enforced
  - Restores films.status = 'published', marks update 'rejected', logs action
- GRANT EXECUTE on all 3 RPCs to authenticated

**Verify:**
```bash

```
