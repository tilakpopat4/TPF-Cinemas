<threat_model>
- Threat: Unauthenticated user or non-filmmaker attempting to submit film.
  Mitigation: Supabase RLS enforces `filmmaker_id = auth.uid()` on `films` and `submit_film()` RPC verifies caller owns the film.
- Threat: Submitting film without poster, video, or licence.
  Mitigation: `submit_film()` Postgres function performs strict validation and rejects submission if any requirement is absent.
- Threat: Malicious file upload in poster storage.
  Mitigation: Client validates MIME type and file size (<5MB), and Supabase Storage bucket policy limits to image MIME types.
</threat_model>
